# Aplicación KMP para Android

Cliente de Catálogo y Turnos para registro, búsqueda de profesionales y gestión de reservas propias. Android debe permitir completar el flujo requerido por el enunciado.

**Estado:** preparación documental; sin implementación, build ni comandos de ejecución. La arquitectura KMP está pendiente de las indicaciones del profesor.

- [Casos de uso, diagrama y decisiones pendientes](docs/use-cases/README.md).
- [Issues publicados](https://github.com/prog2-perassiferrara/frontend-kmp/issues).
- [Reglas de trabajo](docs/GENERIC_RULES.md) y [guía mobile](docs/MOBILE_GUIDELINES.md).
- [Plantilla SPEC](docs/SPEC_TEMPLATE.md), [plantilla PLAN](docs/PLAN_TEMPLATE.md) y [prompts del workflow](docs/PROMPTS.md).

El flujo es CU → issue → SPEC → PLAN → TASKS → implementación autorizada. Los once CU están aprobados y los catorce issues publicados; esto no aprueba SPEC/PLAN ni autoriza implementación. Las fuentes compartidas y las instrucciones están referenciadas en [AGENTS.md](AGENTS.md); deben estar disponibles en el workspace para continuar el trabajo.
